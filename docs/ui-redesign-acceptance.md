# 双端 UI 重构验收记录

## 范围与结论

本记录归并本轮 Android 与 Web UI 重构的逻辑页面、弹窗簇、保留的宿主/引擎边界及现有验证证据。`build/ui-redesign-validation/coverage.md` 是实施前 Manifest 入口及长尾页面的核对基线；它统计 53 个 Activity 声明、合并别名后的 46 个逻辑 Activity 屏幕，不能作为本轮运行通过证明。

早先补充验收使用 PFZM10/API35 真机（1080×2412、density 480、fontScale 1.15，不记录设备 serial），仅安装隔离 QA 包 `io.legado.app.debug`，未覆盖 `io.legado.app.release`。用户要求之后只在既有 API36 模拟器验收，不再操作真机。R75 API36 本地 QA R8 包现已构建并完成所列定向测试、About 与 RSS 普通触控 smoke；产物、签名与边界见本轮行。API 26 测试 AVD 已删除，SDK、系统镜像与 `minSdk=26` 未改，API26 运行记录仍为历史。
历史 Web commit f5cad386f 的 12 项新增检查通过，5 宽度 × 浅/深主题共 10 屏；早先恢复版 173/173、36 张截图仍为独立历史矩阵，不作为当前工作树结果。

整体验收尚未完成。R54、R56、R63、R65 与 R74 的 API36 模拟器和 R8 记录均是对应旧构建的历史结果；R75 是当前 API36 R8 QA 候选，不能将它扩展为全 App 验收。R36 模拟器高 jank 与录像缺帧保留为负向历史证据。真机性能/动效和真实 AI/TTS Provider 效果未验收；用户明确要求不启用 TalkBack。

## 功能契约静态核对

源码接线核对关注用户可完成的闭环，而非仅存在页面或按钮：

- 列表和详情：查询/过滤/排序 → 打开/编辑 → 保存或取消 → 返回原上下文；涉及书架、发现、搜索、书籍/源/规则、RSS 及管理页。
- 配置与偏好：初始值读取 → 临时编辑 → 保存写入原 Preference/AppConfig/数据库；取消不提交草稿；重置/删除/导入/导出仍调用原业务入口。
- 异步操作：加载、测试、更新、调试、导入等状态与原任务/协程/回调相连；取消和错误路径由宿主/既有执行器处理。
- 系统边界：Activity Result/SAF、权限、剪贴板、分享、通知、后台服务、WebView 与多媒体引擎保留原平台接口。

以上为静态代码对照，不等价于实机操作通过，也不覆盖没有配置的外部 Provider、账号或在线服务。
