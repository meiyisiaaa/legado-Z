# 双端 UI 重构验收记录

## 范围与结论

本记录归并本轮 Android 与 Web UI 重构的逻辑页面、弹窗簇、保留的宿主/引擎边界及现有验证证据。`build/ui-redesign-validation/coverage.md` 是实施前 Manifest 入口及长尾页面的核对基线；它统计 53 个 Activity 声明、合并别名后的 46 个逻辑 Activity 屏幕，不能作为本轮运行通过证明。

验证边界：API 26 测试 AVD 已按用户要求删除，API 36 保留；共享 SDK、系统镜像与 minSdk=26 未改，API 26 运行记录仅为历史。R63 test-only build PASS（63.328 秒），R64 stop PASS（1.625 秒）；`build/ui-redesign-validation/native/api36-r63-import-tests.txt` 的整合 XML layout/recreation 测试 PASS 1/1，用时 23.443 秒。该项覆盖 30 条初始数据、font scale 2、取消首项、设置 QA group 并 Add、Activity.recreate、顺序/数量/选择状态与菜单标题、字段开关回读、滚动末项、页脚可达，以及 Cancel 后 Room 未写入。R61 最近完整 focused batch 为 5 项 4 PASS / 1 FAIL；失败仅为 `source1`/`source10` 子串 matcher 错误，没执行重建，R63 仅修正测试选择器，生产 APK 未改。R59 旧独立测试的 tag 观察和 R61 失败细节留在下表。R65 release R8 build PASS（807.016 秒），R66 stop PASS（1.875 秒）；签名与 APK 元数据见下表。R65 签名包的定向 API 36 模拟器 UI 烟测及最终 crash 状态检查均已通过；全 App 和整体验收仍未完成。
Web commit f5cad386f 的 12 项新增检查通过，5 宽度 × 浅/深主题共 10 屏；早先恢复版 173/173、36 张截图仍为独立历史矩阵。

整体验收尚未完成。R54 API 36 模拟器字号重建手动路径通过；R63 的整合 XML layout/recreation 自动化也已 1/1 通过，生产 APK 未修改。R56 API 36 模拟器本地 SAF 文件选取、书架阅读、翻页、重开与删除测试书籍通过。R65 签名 R8 包的 API 36 模拟器定向烟测已通过，含四导航、Replace 保存回读和删除、HttpTTS 表单及取消、QR 导入字体 1→2 重建、ThemeList、FileManager 路径和 BookInfo 页面。R65 烟测用 10 条导入项，不扩张 R63 debug 包的 30 行重建结果。首个 Launcher dump 无 root，更新日志后 Main 正常显示；不作为启动性能通过。`native/api36-r65-device-final.json` 记录最终字体和窗口/转场动画比例为 1.0、animatorDurationScale 使用默认值；`native/api36-r65-final-crash.txt` 为空且 `crashBufferEmpty=true`。用户明确接受本轮真机性能与动效、真实 AI/TTS Provider 效果未验证；R36 模拟器高 jank 和录像缺帧保留，性能未通过。

## 功能契约静态核对

源码接线核对关注用户可完成的闭环，而非仅存在页面或按钮：

- 列表和详情：查询/过滤/排序 → 打开/编辑 → 保存或取消 → 返回原上下文；涉及书架、发现、搜索、书籍/源/规则、RSS 及管理页。
- 配置与偏好：初始值读取 → 临时编辑 → 保存写入原 Preference/AppConfig/数据库；取消不提交草稿；重置/删除/导入/导出仍调用原业务入口。
- 异步操作：加载、测试、更新、调试、导入等状态与原任务/协程/回调相连；取消和错误路径由宿主/既有执行器处理。
- 系统边界：Activity Result/SAF、权限、剪贴板、分享、通知、后台服务、WebView 与多媒体引擎保留原平台接口。

以上为静态代码对照，不等价于实机操作通过，也不覆盖没有配置的外部 Provider、账号或在线服务。
