# Final Design QA Report（当前验收候选，非最终完成）

本报告评估 Android 与 Web 的产品体验和视觉交互，基线是 Legado 原有布局、信息层级、操作位置及用户主题。每项结论只覆盖引用的实际页面与路径；源码改动、截图、模拟器操作和自动化测试分别按其证据范围描述。

当前 Android 交互与截图证据来自 API 36 模拟器。R65 release R8 构建、签名和 ZIP 16 KiB 页边界对齐检查已通过；本地测试签名包的定向 UI 烟测通过，覆盖 Launcher/四个导航、Replace、HttpTTS 表单、QR 图库字号重建、ThemeList、FileManager 路径和 BookInfo。冷启动首个 dump 曾无根节点，随后更新日志后 Main 正常显示；这不作为启动性能通过。`build/ui-redesign-validation/native/api36-r65-device-final.json` 记录字体比例与窗口/转场动画比例为 1.0、animatorDurationScale 使用系统默认值；`build/ui-redesign-validation/native/api36-r65-final-crash.txt` 为空，`crashBufferEmpty=true`。最终状态截图为 `build/ui-redesign-validation/native/api36-r65-final-shelf.xml/png`。本报告仍为验收候选（`final=false`）。API 26 测试 AVD 已按用户要求删除，`minSdk=26` 未变。Web commit `f5cad386f` 的 12 项新增检查覆盖 5 种宽度与浅/深主题；完整构建、运行和历史结果详见[双端 UI 重构验收记录](ui-redesign-acceptance.md)。用户已接受本轮实体设备性能与动效、真实 AI/TTS Provider 效果未验证；这些项目不记为通过。

## 1. 排版 Typography

- **当前状态：** R65 签名 R8 包在 API 36 模拟器上实际打开 HttpTTS 表单，标签不重复、hint/underline/cursor 为红色；Gboard 两个可见状态标记均为 true，Save 可达。截图见 `build/ui-redesign-validation/native/api36-r65-tts-focus.png`，R63 同一表单像素检查仍是先前证据。
- **发现的问题：** Compose 外层文本与 TextInputLayout hint 重复；全屏 CodeEdit 以 hint 作为标题，直接删 hint 会丢失编辑器标题。
- **已执行优化：** 删除重复的外层文本，保留 hint，并将间距从 12dp 收至 8dp。R63 模拟器截图确认实际渲染符合预期。
- **剩余可提升空间：** 本轮未提交 HttpTTS 表单，也未验证真实 TTS Provider 的输出；其他表单的排版未由该路径覆盖。

## 2. 间距 Spacing

- **当前状态：** R65 签名 R8 包中 ThemeList 四行自然收高；FileManager 搜索框和 QR 手电筒为 48dp。R65 导入弹窗从 10 条列表将系统字体 1→2 后，仍有 10 个唯一项、选中数 9/10，首项保持未选且页脚完整可见。API 36 模拟器证据见 `build/ui-redesign-validation/native/api36-r65-*`；R63 的 30 条重建属于此前 debug 测试，不作为本次 R8 覆盖。
- **发现的问题：** ThemeList 少量内容曾占用近整屏；导入弹窗把可用空间错误留给内容区，字体放大后挤压操作页脚；Source/RSS 底部操作区靠近系统手势区域。
- **已执行优化：** ThemeList 按内容自然收高；导入列表依工具栏和页脚实际尺寸使用剩余空间，并在重建后保留列表状态；Source/RSS 底部安全区及 FileManager/QR 点击区按系统 Insets 和可触达尺寸调整。R63 字体缩放重建路径通过。
- **剩余可提升空间：** 已验证的 Insets、字体比例和窗口尺寸仅代表对应 API 36 模拟器页面；其他屏幕和真实设备布局仍需按实际范围核对。

## 3. 视觉层级 Visual Hierarchy

- **当前状态：** 书籍详情主要操作在 320dp、字体比例 2 下保持等高；R65 模拟器中长按书籍可打开 BookInfo，实际页面显示默认封面及原创 QA 内容（`build/ui-redesign-validation/native/api36-r65-book-detail.xml/png`，非 mockup）。Video 404 错误画面不再叠加原生播放圆标。书架、书源字段和原有操作入口仍遵循 Legado 组织方式。其他证据见 `build/ui-redesign-validation/native/api36-r45-runtime-summary.json`、`api36-r41-video-error.png` 和 `api36-r41-video-recovered.png`。
- **发现的问题：** 狭窄窗口和较大字体会放大按钮高度差；视频错误提示曾与原生播放控件重叠，遮挡状态信息；重构若替换首页和字段组织会削弱用户熟悉的层级。
- **已执行优化：** 统一详情操作按钮尺寸，隐藏错误态重复播放图标并修正播放器初始化顺序；保留书架、书源及阅读器既有组织和位置，放弃此前的新首页概念。
- **剩余可提升空间：** 当前证据是若干重点页面与播放器路径，不是全 App 逐页的视觉层级评审；Vietnamese 字符测试及上述尺寸覆盖不代表所有语言和字号组合。

## 4. 色彩 Color

- **当前状态：** R65 签名 R8 包上 HttpTTS 的 hint、下划线和光标实际均呈主题红色；深色标题和 FileManager 浅色底部系统栏对比也已分别在 R41、R48 复验。R65 焦点截图为 `build/ui-redesign-validation/native/api36-r65-tts-focus.png`。
- **发现的问题：** 部分控件曾绕过 ThemeStore 语义色，导致深色主题标题发黑、系统栏与浅色内容对比不足，输入焦点的旧 tint 也没有实际改变像素颜色。
- **已执行优化：** 颜色改用主题语义角色，修正深色标题、FileManager 系统栏对比和 HttpTTS 支持 tint。R63 截图是焦点颜色的渲染证据，R59 洋红下划线只作为修复前基线。
- **剩余可提升空间：** R65 已复核所列主题与页面；其他用户主题、系统栏组合及特殊显示模式仍未逐一核对，尚需按目标范围补验。

## 5. 动效 Motion

- **当前状态：** 源码保留既有交互反馈规则并处理媒体初始化和连接收尾；现有截图只证明静态画面。R36 模拟器录像有缺帧记录，本轮实体设备动效按用户接受边界未验证。
- **发现的问题：** 尚无可证明页面转场连续性、快速操作可中断性或减少动态效果下表现的本轮设备记录；R36 录像缺帧也使历史动效观察不完整。
- **已执行优化：** 媒体初始化顺序和连接生命周期已有源码调整；报告将源码规则与实际连续播放/转场验证分开，未把截图视为动效通过。
- **剩余可提升空间：** 动效质量仍未验收。用户已接受本轮实体设备动效未验证；模拟器录像缺帧保留，不能据此宣称流畅或把现象单独归因于模拟器。

## 6. 微交互 Micro-interaction

- **当前状态：** Web 搜索结束后可返回书架，已入架内容会被过滤，零新增结果有解释；WebSocket 正常结束、取消和无 ACK 超时释放连接有对应 R50 检查。Web 检查记录为 commit `f5cad386f` 的 12 项新增检查。
- **发现的问题：** 搜索结束仍显示“取消搜索”，用户难以判断当前结果；已入架内容会让空结果看起来像搜索失败；网络关闭时等待可能没有明确完成反馈。
- **已执行优化：** 结果态文案改为返回书架，过滤书架已有项并解释零新增；连接关闭采用 ACK、5 秒期限、幂等清理，并先关闭输出以解除等待。R50 的四项 WebSocket 检查覆盖正常码、取消和无 ACK 释放路径。
- **剩余可提升空间：** 具体检查只覆盖所列请求和关闭路径；不同服务端与网络故障的提示、恢复和可访问反馈仍未穷尽。

## 7. 导航与操作 Navigation & Usability

- **当前状态：** R65 签名 R8 包中四个主导航正常；FileManager 从根目录进缓存目录时面包屑更新为 root/cache，`..` 返回后同步回 root。搜索结果出现时 IME 收起；源编辑器保存/未保存返回另有 API 36 模拟器证据。相关 R65 记录见 `build/ui-redesign-validation/native/api36-r65-*`，此前证据见 R48、`api36-r45-runtime-summary.json` 和 R44 SourceEditor 记录。
- **发现的问题：** 进入子目录后路径提示曾滞后；搜索结果与软键盘争夺可视空间；源编辑器离开时需要区分保存和放弃修改。
- **已执行优化：** 目录导航使用当前路径重算面包屑；搜索进入结果模式时收起输入法；源编辑器保留保存和返回确认流程。R56 的系统文件选择、加入书架、阅读和重开路径另有 API 36 模拟器记录。
- **剩余可提升空间：** 结果覆盖上述具体入口，不证明全应用返回栈、外部 Intent 和所有文件授权流程都一致；Chrome 原生软键盘未通过本轮验证。

## 8. 适配 Adaptive Layout

- **当前状态：** R65 签名 R8 包在 API 36 模拟器上通过导入 10 条列表的字体 1→2 重建与页脚可见性检查；此前还覆盖 320dp/字体比例 2 下的书籍详情、RoleTTS/MCP 横向布局，以及 Web 五种宽度的浅色和深色界面。R63 30 行重建为 debug 测试证据，不扩张为本次 R8 覆盖。
- **发现的问题：** 窄屏及大字号可能压缩详情按钮与导入页脚；横屏内容需按原有导航关系重新排布；Web 搜索和详情曾有文字、标题对比与裁切问题。
- **已执行优化：** 调整详情按钮等高、导入列表与页脚的空间关系，并修正 Web 自然高度、标题对比和布局细节。Web `f5cad386f` 的 10 屏矩阵对应 5 种宽度 × 2 种主题。
- **剩余可提升空间：** 适配结论限于所列尺寸、页面和主题。更多窗口尺寸、显示缩放、外接键盘及 Chrome 软键盘仍未覆盖；模拟器结果不等同于实体设备验收。

## 9. 产品状态 Product States

- **当前状态：** R65 签名 R8 包中的 Replace 可新增、保存、重开回读字段并确认删除后回到空列表；QR 图库导入弹窗中的取消选择、字体重建和取消返回路径通过。较早 API 36 模拟器证据还显示音频 404 暂停/上一章恢复、视频错误重试/有效章节画面；主页面加载骨架见 `build/ui-redesign-validation/native/api36-r56-main-ready.png`。R65 运行证据见 `build/ui-redesign-validation/native/api36-r65-*`。
- **发现的问题：** 音频错误后 MediaSession 曾继续呈现错误播放状态；视频 404 提示与原生播放控件重叠；图库解码对非方形拉伸图不稳定；空 Replace 列表缺少明确下一步。
- **已执行优化：** 音频错误后更新为暂停状态及失败章节 metadata，视频错误态隐藏重复控件并保留重试与章节恢复；QR 图片按比例缩放后解码；Replace 空态可进入创建流程。R65 签名 R8 实际核对 Replace 保存/回读/删除和 QR 字体重建取消路径；较早证据见 `build/ui-redesign-validation/native/api36-r45-runtime-summary.json`、`api36-r41-video-error.png`、`api36-r50-gallery-selected.png` 和 `api36-r48-replace-cleaned.png`。
- **剩余可提升空间：** 这些记录覆盖明确的成功、空态、拒绝或错误分支，不代表所有页面的加载、空、失败和恢复状态均已检查。真实 AI/TTS Provider 效果按用户接受边界未验证。

## 10. 性能 Performance

- **当前状态：** R36 API 36 模拟器混合会话记录 548 帧、470 帧卡顿（85.77%），p50 53ms、p90 150ms、p95 300ms；该数据为负向历史证据，性能尚未通过。本轮实体设备性能按用户接受边界未验证。
- **发现的问题：** R36 采样混合了首次使用、录屏与导航，不是隔离稳态测量；录像缺帧仍保留，不能单独归因为产品或模拟器。
- **已执行优化：** 列表按需加载和连接生命周期有源码层调整，但现有记录没有可对照的隔离 FPS/帧时数据，不能据此声称量化性能改善。
- **剩余可提升空间：** 性能结论仍为未通过/未完成。用户接受本轮实体设备性能不测；R36 高 jank 与录像缺帧继续保留，后续需以可复现、隔离的测量确认效果。

## 11. 无障碍 Accessibility

- **当前状态：** QR 手电筒控件为 48dp，开启/关闭时名称会更新；ReaderMenu 的“自动亮度”语义值显示启用状态。证据来自 API 36 模拟器 R48 控件范围与 R50 XML/语义检查。
- **发现的问题：** 开关如果只暴露控件名称或格式化数值，屏幕阅读器用户无法得知当前开关状态；较小热区也会增加触控难度。
- **已执行优化：** QR 开关增加明确状态名称并达到 48dp；ReaderMenu 标签改为本地化的启用/禁用状态。
- **剩余可提升空间：** TalkBack 实际朗读、焦点顺序、动态状态播报及 Web 完整键盘可达性未验证；标签检查不能替代完整辅助技术验收。

## 12. 原创性与品牌 Originality & Brand

- **当前状态：** Android 与 Web 回到 Legado 原版布局、信息层级和操作位置；保留书架、来源、阅读和用户主题的熟悉组织。Web 以 5 种宽度的浅/深主题覆盖代表页面。
- **发现的问题：** 此前的新首页概念偏离用户要求的原版结构；只看单个组件容易误把局部改造当成全产品视觉定稿。
- **已执行优化：** 放弃新首页方向，围绕 Legado 原有信息关系优化排版、状态反馈、Insets、键盘和错误提示；不改变熟悉的业务入口和字段组织。
- **剩余可提升空间：** 当前范围展示的是有证据的局部改进，不是所有页面均完成最终美术评审；不据此宣称获奖或整体视觉已最终定稿。

## 最终自检结论

**当前为验收候选，非最终完成（`final=false`）。** 视觉上，R65 签名包的 HttpTTS 焦点色、ThemeList、导入字体重建及实际 BookInfo 页面已在 API 36 模拟器查看；交互上，R65 的四个导航、Replace、HttpTTS 取消、QR 字体重建和 FileManager 面包屑烟测通过；体验上，错误、空态、键盘和加载反馈已有局部证据，但并非全 App 状态覆盖；适配上，R65 的导入验证仅为 10 条列表，R63 的 30 条重建属于 debug 测试，Web 另有五宽浅/深矩阵，均不能外推至所有设备。性能未通过：R36 混合采样显示高 jank，实体设备性能与动效按用户接受边界未验证。原创性以保留 Legado 原有布局和信息层级为方向，整体全页评审仍未完成。真实 AI/TTS Provider 效果未验证。R65 最终状态文件记录 `crashBufferEmpty=true`、最终 crash 文本为空；因此烟测结束状态确认无 crash 记录，但仍不能据此宣告全 App 或最终验收完成。
