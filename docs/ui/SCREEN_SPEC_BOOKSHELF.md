# SCREEN_SPEC · 书架

状态：共享 Compose 书架内容与默认分组标签宿主的首轮实现已完成。实际运行、截图及边界见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)。实现保留业务、存储、导航入口与用户显示偏好。

## 主要任务与信息优先级

从当前分组中找到书、了解已读与更新、打开阅读；长按进入既有详情。分组切换、搜索、更多菜单和底部目的地保留位置。

1. 书名与封面：识别对象。普通列表书名最多两行，紧凑列表一行；网格沿用现有显示偏好（显示、隐藏、封面叠字），显示时最多两行。书名完整名称作为条目可访问名称。
2. 作者：辅助识别。普通列表独立一行，紧凑列表与当前章节同行。
3. 当前章节、最新章节：保留顺序，普通列表以“读至 / 更新”短标签和细竖线组成边注；标签自然宽度、最小 28dp，之后留 8dp 间隔；当前章节用次级前景，最新章节用主前景。紧凑列表保留原有章节图标。
4. 未读与更新：右上角紧凑徽标；数字使用 `labelMedium`，最小高 20dp。加载目录时原位显示更新状态，不把它做成主操作。
5. 更新时间：仅按用户开关显示，不挤掉未读数字或书名。

## 布局与视觉焦点

- 本轮保持“分组与工具 → 书籍 → 底部导航”的书架任务顺序；此处描述当前实现，不限制后续阶段的其他布局或功能探索。
- 普通列表内容边缘 16dp，封面 66dp × 88dp，图文间距 12dp，元数据间距 3dp；长标题自然增高整行。
- 紧凑列表封面 48dp × 64dp；保留既有高密度布局。
- 网格保留用户保存的 2–6 列偏好、书名显示模式及条目间距；实际列数按可用宽度和字体缩放收缩，最小单元格为 `48dp × max(1, fontScale)`，不覆盖保存的偏好。不新增作者或章节，避免破坏原网格信息组织。
- 普通书名以现有 titleMedium 为基底定义组件角色：系统 Serif、18/26sp、Medium（API26 中文采用系统回退）；辅助信息继续使用 MaterialTheme 排版角色。颜色来自 LegadoTheme；书籍封面继续使用 CoverImageView。
- 无单条卡片背景与额外阴影；主要焦点是书名与封面，更新徽标只是辅助。

## 状态

| 状态 | 表现与可用行为 |
| --- | --- |
| 正常 | 按列表/紧凑/网格偏好展示；点击打开，长按详情，分组可切换与编辑。 |
| 空 | 现有书架图标、短标题、较轻的原有操作指引居中；保留顶部搜索和菜单；内容区窄屏/大字体可滚动。 |
| 加载 | 可读加载状态与稳定骨架；对齐普通列表的 16dp 边缘与 66dp 封面；不添加无限闪烁。 |
| 数据读取失败 | 错误图标、标题、具体原因、重试按钮；长原因可滚动，重试随内容保持可达。 |
| 单书更新失败 | 保留书籍与阅读入口并展示单书失败状态；不把单书失败替换成整页错误。 |
| 长文本 | 普通列表标题两行后省略；作者和章节保持单行省略；完整名称与内容仍暴露给辅助功能。 |
| 更新中 | 复用现有 CircularProgressIndicator；系统禁用动画/墨水屏时使用静态刷新图标。 |

## 交互反馈

- 点击/长按及刷新、详情、分组回调契约保持不变。
- 条目使用现有 combinedClickable 的按压/焦点反馈；按压缩放 0.985、120ms，状态/重排 240ms。
- 本轮不改变页面切换、返回栈、排序、下拉刷新或封面请求的职责。
- 尊重 LocalLegadoMotion；禁用动画时无非必要位移或旋转。
- 错误重试触发原有 onRetry。空态没有新增业务按钮，用户继续使用原有搜索/导入入口。

## 响应式与辅助功能

- 实测目标：常规 1080×2400 / 420dpi（约 411dp）与小屏 840×1680 / 420dpi（320dp）。尺寸是同一 API36 模拟器的显示配置，不冒称两台真机。
- 大字号检查 2 倍字体；内容自然增高，不能靠固定行高裁掉书名或错误按钮。
- 最小交互目标沿用 Android 48dp；网格最小单元格随字体比例增大，在不改变保存偏好的前提下限制实际列数，避免大字号书名和徽标挤压。
- 不以颜色单独区分状态：徽标有数字与语义，更新有可访问名称，错误有文本和重试。
- 书名、分组为可访问名称；封面内部文字不重复读出；动态加载状态使用适度的 live region。
- 宿主继续处理状态栏和导航栏 Insets；本轮不改变系统栏策略。
