# 目录内容页规格

## 范围与层级

本轮重构 `ChapterListScreen` 呈现层，沿用 `DESIGN_SYSTEM.md` 的主题语义、16dp 内容边界、细线和边注组织。章节使用便于扫读的正文角色，书名使用独立的 18sp Serif 角色。阅读正文、字体偏好、页边距和引擎保持。

`TocActivity` 继续拥有目录/书签 Tab、搜索、菜单、倒序、替换开关和字数开关；`ChapterListFragment` 继续拥有 DAO 查询、缓存集合、打开结果和长按完整章名提示。搜索框、菜单、书签及 Book 数据模型沿用既有职责。

## 章节与底部定位

- 章节目标至少 48dp，左右内容边界 16dp；使用轻按压反馈，条目直接落在连续页面表面。
- 普通章名采用 `bodyLarge`、`onSurface`，最多两行；卷名采用紧凑标题层级及分隔线，形成章节组的节奏。
- 当前章同时有 `selected` 语义、强调侧线、强调标题和勾选标记。当前章的未缓存图标与选中标记分别表达状态。
- 标签和启用的字数信息保留，次级正文最多两行；卷名使用独立标题。VIP 未付费继续显示锁标记，网络正文按实际缓存状态显示标记。
- 长标题省略仍保留完整语义和长按完整章名回调；替换规则继续在原异步路径计算，输入章名或替换上下文变化时刷新显示标题。
- 底部为平面定位栏，以细线与章节区分隔。当前章信息最多两行，轻标签与正文分级；点击、长按均定位当前章。原首尾定位按钮至少 48dp，空目录禁用。
- 进入目录仍定位当前章邻近位置；用户点击首尾或当前定位时遵循原动画开关。搜索后的定位使用过滤结果索引，数据库及筛选语义保持。

## 状态与导航动作

- 加载：使用真实 `isLoading` 状态及原 `data_loading` 文案和 live region；系统减少动画时改静态目录图标，保留状态文字。
- 空目录、搜索无结果：使用各自独立文案表达。
- 失败：保留实际错误、live region 和原重试回调；长错误随目录容器滚动，用户通过原入口重试。
- 打开章节、长按完整章名、返回、搜索、菜单与书签导航沿用现有职责。
- 浅色、深色、用户主题和墨水屏使用既有语义颜色和形状；按压和列表变化统一使用 `LocalLegadoMotion`。

## 验证

`ChapterListScreen` 保留原接口，固定目录 fixture 直接注入 `ChapterListUiState` 与回调，检查选中与打开、完整章名长按、卷名/字数/VIP/缓存、首尾与当前定位、章名同身份更新、空/搜索空/加载/长错误重试及长文本布局。

截图复用 UiAutomation 整窗采集，支持 `visualPrefix` / `visualFontScale`，保存在应用外部目录 `toc-visual/<visualPrefix>-<state>.png`。既有可访问性测试只适配必要的本地化标签选择器。

本轮已在 API36 模拟器执行目录状态、章节操作、定位及常规屏/320dp 小屏、1×/2× 字体相关检查。窄屏实测推动首尾定位按钮显式使用 48dp；具体结果与大字体 fixture 修复后的复验记录见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)。真机、TalkBack 实际朗读和全阅读引擎属于后续验证范围。
