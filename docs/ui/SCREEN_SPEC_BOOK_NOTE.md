# 书目备注 SCREEN_SPEC

## 目标与边界

为书架中每本书保存自由文本备注，独立于书源简介、自定义简介、脚本变量及章节书签。通过现有书籍信息编辑入口编辑，详情页仅在备注非空时展示；不增加书架常驻操作或新的导航层级。

备注存于 `books.userNote` nullable TEXT，Room 90→91 仅增加该列。整书备份随 Book 序列化保存和恢复；普通书架分享沿用原字段白名单，单本分享从完整 JSON 中移除 `userNote` 并保留其余字段。远程 Web 的旧版整书保存入口保留本地已有备注，Web 进度同步沿用原进度字段。已启用 Web 服务的阅读客户端沿用整书读取协议，返回内容包含备注。恢复备份遵循现有整书恢复语义，可用旧备份覆盖当前备注。

## 布局与交互

- 详情沿用现有封面、元信息、简介和底部阅读操作结构。备注位于简介之后，以细分隔、主题 primary 小标题和正文呈现，作为书页边注的延续，不新增装饰卡片。正文自然换行，不截断，并可选择复制。
- 编辑页采用66×88dp封面和共享书名角色的平面预览、16dp边缘和主题small形状；简介4–10行随字体与内容伸展。在简介之后新增独立多行备注输入。标签为“书目备注”，用一条必要说明交代“随完整备份保存，不包含在书架分享清单中”。保留原有工具栏保存入口；返回/取消不写备注。
- 输入使用现有 Material 3 OutlinedTextField、语义标签和主题颜色，至少四行，限制可见行数后内部滚动，外层仍可滚动。保留 IME inset，窄屏、大字号和键盘弹出时可到达输入与保存入口。
- 草稿由编辑 Activity 状态持有并通过 Bundle 恢复；加载书籍只初始化草稿一次。修改草稿不修改实体或活动阅读对象，保存成功才发布结果，失败保留输入并沿用现有错误提示。
- 空白输入保存为 null；非空文本保留用户原始换行和前后空格。无人工字数上限或静默截断。

## 数据保存与消费者

备注使用专属 DAO 列更新，不用旧 Book 快照覆盖阅读进度。现有书籍信息编辑在事务内定点更新编辑字段与备注；成功后只同步活动文本、漫画、音频和视频模型的编辑字段，保留这些模型的阅读位置和配置。换源 `migrateTo`、信息更新 `updateTo`、后台刷新 `sync`、重定向替换和同名作者旧书合并均保留备注。新 Web 请求缺省备注或携带备注时均不能通过旧整书保存入口覆盖已存备注；编辑备注使用本地现有入口。

通用 `BookDao.insert/update/replace` 不负责修改已有备注，防止后台持有的旧实体或 REPLACE 覆盖新编辑的数据。批量 update 只查询 bookUrl/userNote 投影，每 900 个 URL 分块避免 SQLite 绑定变量上限。完整恢复明确使用原始实体 insert/update 来恢复备份里的备注（包括旧备份中缺省的 null）；原始 DAO 方法只用于该恢复和受保护写入方法内部。详情换源通过 `Book.replaceWith` 在 DAO 事务里继承最新备注，并执行与 `Book.delete` 相同的活动阅读模型清理。

在线书转换本地书的备注归属与元信息保存位于同一事务。存在本地记录时以其备注为准（包括已经清空的 null）；本地记录不存在时读取在线记录的最新备注，只有相应记录均不存在才回退传入快照。不得把“现存记录的空备注”误判为“没有记录”并恢复旧备注。

## 状态与验收

覆盖无备注、有备注、多段长文本、清空、取消、旋转恢复、保存失败以及继续阅读后备注保留。迁移测试验证旧书、进度和阅读配置不变；数据测试验证定点备注更新、换源/刷新保留、Gson 完整备份往返。Compose 测试覆盖详情条件展示、编辑回调、长文本滚动可达和大字号布局。
