# SCREEN_SPEC · 发现与搜索

本轮在已选“书页边注”设计系统上实现，保留现有书源、筛选、搜索、停止/继续、分页、历史和封面共享元素通路。没有新书源、推荐内容或无真实后端的操作。

## 发现

- 主要任务：按现有分组找到书源，展开分类并进入内容；长按保留编辑、置顶、登录、搜索、刷新、删除。
- 层级：书源名称是主信息，已有书源组为辅助；使用16dp对齐边缘、至少48dp展开目标、细分隔和展开区边线，替代逐行色块。分类仍由现有 renderer/slot 提供。
- 正常：长名称最多两行；组名一行省略但语义完整。选中展开由状态、箭头和结构共同表达。
- 加载：保留真实分组/源/分类加载状态，无额外定时伪进度；减少动画时进度使用静态刷新图标。
- 空：真实无书源保留原导入指引；筛选无匹配与真实空分开呈现，不改查询。
- 错误：短标题与具体原因分级，长原因可滚动，重试调用既有回调；分类错误和已有分类同时可达。
- 交互：展开/收起、重排服从现有motion token；返回、原菜单和长按保持；窄屏、大字检查内容、重试与菜单可达。

## 搜索

- 主要任务：从历史/本地匹配发起搜索，识别结果、来源数量、是否已在书架，打开书籍或继续扫描。
- 层级：66×88dp封面、12dp图文间距、16dp内容边缘；书名复用共享Serif 18/26sp角色、最多两行；作者、分类、最新章节、简介依次出现。
- 已在书架：用文字/图标状态取代仅绿色圆点，读屏可识别；来源数量用语义文字表达。
- 搜索结果：保留全部现有字段、来源数量和封面过渡引用。简介两行省略，分类自然换行，长书名/章节保留完整语义。
- 尚未搜索：保留历史、本地匹配与清除，删除命中区域至少48dp。
- 正在扫描：现有搜索状态保留，并对等待文本提供语义；停止、继续及分页仍走原回调。
- 无结果：仅在非搜索中、没有更多页且结果为空时呈现，区分手动停止；不把正在扫描或暂停误报无匹配。没有真实搜索错误状态时不虚构错误重试。
- 键盘/响应式：输入框的焦点、IME Search、返回隐藏键盘以及现有焦点恢复契约保持；结果可滚动。检查320dp与常规屏、两倍字体、空和暂停。

本轮已执行发现展开/长按菜单、搜索状态与继续操作、长内容和历史删除等设备检查，分项与原生截图见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)。实际书源网络、真机与 TalkBack 实际朗读列入后续验证。
