# SCREEN_SPEC · TXT 目录规则

## 任务与布局

管理页负责查找、编辑、启停、排序和批量管理目录识别规则；阅读器内的选择页负责选定本书使用的规则。沿用现有矿绿主题、顶部添加/导入入口及底部操作区。

列表先显示规则名称，再显示已有示例。左侧为勾选或单选控件，右侧依次为启停、编辑与更多操作。列表采用 `LazyColumn` 按需渲染，DAO 一次观察全部有序规则。

## 状态

| 状态 | 行为 |
| --- | --- |
| 正常 | 点击名称/左侧控件选择；启停立即反馈并持久化；编辑保留同一规则 ID。 |
| 空 | 显示已有空态文字，保留添加与导入入口。 |
| 首次读取 | 等待原有数据库观察结果，沿用当前呈现；本轮未新增加载状态。 |
| 读取异常 | 沿用原有 AppLog 记录路径；本轮未增加界面错误和重试状态。 |
| 长名称/示例 | 名称一行、示例最多两行省略；控件可访问名称包含完整规则名。 |
| 编辑校验失败 | 沿用编辑器原有字段错误与保存校验。 |

## 交互与约束

- 普通上下滑动浏览全部规则；列表按稳定 ID 保持条目身份。
- 长按内容区排序；管理页长按左侧区域连选，快速经过多行时补齐中间项。
- 长按后停在顶部/底部 56dp 区域，按距边缘的比例连续滚动；结束或取消时停止，发生排序才保存。
- 置顶/置底、导入导出、批量启停和删除继续使用既有操作。
- 管理页保留底部批量栏；选择页保留取消/确定及当前选择语义，视图销毁时释放数据收集。
- 常规屏与 320dp 小屏沿用原生安全区、Material 控件及辅助功能语义。本轮设备结果见 [TXT_RULE_SCROLL_FIX.md](TXT_RULE_SCROLL_FIX.md)。
