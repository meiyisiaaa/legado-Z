# 书籍详情 · 矿绿书衣

状态：A 概念已由用户选择；实现与设备验收结果见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)。

主要任务是识别书籍、了解当前与最新章节、换源/分组、进入目录和阅读。保留封面、书名、作者、分类的点击和长按，以及原菜单、富文本简介、书架操作与备注。

首屏以与工具栏连续的矿绿色书衣为视觉焦点：左侧实体封面，右侧大书名、作者；来源和分组接在标题下。内容层为纸面，当前/最新章节组成同一阅读区域，目录操作位于区域右上。简介和个人备注用留白、标题和细线组织。底部并排保留书架与阅读操作，阅读是唯一实色主按钮。

常规屏封面136×196dp，书名28/36sp Serif Normal；书签穿过书衣与纸面接缝。小于360dp正常字体使用104×150dp封面与书名横排，分类位于标题侧，来源/分组进入下方；字体达到1.5×时，小封面与身份分行，保留全量书名和操作。章节使用1dp细框和16dp内距分组。页面纵向滚动，底部图标/文字操作按内容增高。触控目标48dp以上，标题有heading语义；全文与长按路径保留。

正常状态展示真实字段；加载使用宿主现有刷新/等待机制；简介为空显示原简介提示；备注为空省略区块。网络错误、无章节、换源失败保留Activity原反馈。长书名、长作者、长来源、长章节可自然换行；分类横向滚动且保留完整语义。

封面沿用原AndroidView与共享元素转场。按钮采用可中断的轻微按压与回弹，状态变化复用统一Motion；系统移除动画/墨水屏时直接反馈。布局变化不额外拖延导航，不新增装饰性加载或假进度。

验收：实际Activity首屏与滚动、目录/换源/分组/封面/编辑菜单，320dp、常规屏、2×字、深色、自定义主题、减少动画及空/长文本fixture。示例概念封面和文字仅用于设计比较，运行页面始终显示用户内容。
