# 书源管理与分组 · 矿绿书衣 V3

本轮执行状态：源码与测试包已构建，相关常规/长文本/错误恢复/触控用例已实际运行；具体通过项、主题fixture修正、最新截图和未验证范围以根目录 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md) 当前A阶段记录为准。下文验收清单描述目标范围，分项执行证据以该报告为准。


## 目标与视觉依据

面向维护大量书源的读者，页面处于 Operate 模式：先识别书源，再进行选择、启停、编辑与批量维护。保留既有工具入口和数据通路，以用户选定的 A「矿绿书衣」建立原创视觉语言。主视觉来自已选详情概念中的深色书衣、浅色纸面、细分隔与明确字号层级；管理页将其转译为清晰的工具界面。

本规格覆盖 `BookSourceManageContent.kt`、`GroupManageDialog.kt`。Activity、ViewModel、Room、规则执行、字符串资源、主题定义与专用编辑器沿用现有实现。共享主题由当前统一系统承接。核心详情页实测后完成本页实现，构建和常规/夜间设备检查已执行，分项证据见根验收报告。

## 颜色、排版与空间

| 元素 | 角色与规则 |
| --- | --- |
| 深色工具栏 | `tertiaryContainer` / `onTertiaryContainer`，延续用户配置的原生工具栏颜色 |
| 页面与列表 | `surface` / `onSurface`，纸面连续铺开 |
| 搜索与工具区域 | `surfaceContainerLow` 或 `surfaceContainer` |
| 选中与主要操作 | `primary`、`primaryContainer` / `onPrimaryContainer` |
| 分隔、辅助文字 | `outlineVariant`、`onSurfaceVariant` |
| 检测失败与删除 | `error`，同时保留文字和控件语义 |

选定方向的参考色为书衣 `#183F38`、纸面 `#F7F7F2`、主操作 `#24675B`；页面代码只读取 Material 颜色角色。用户自定义主题、夜间与墨水屏继续生效。

页面水平主边距 16dp；搜索与列表文字起始线对齐。书源名称使用 `titleMedium`，辅助域名与分组使用 `bodySmall`，工具标签使用 `labelLarge`，弹窗标题沿用 Material 标题角色。系统字体与字号缩放继续生效。输入与局部工具底使用 8–12dp 圆角。列表通过 1dp 分隔与文字节奏组织，避免每条书源独立大卡片、装饰性编号和指标块。

## 书源管理布局

1. **顶部工具栏**：保留返回、书源标题、排序、分组与更多四类入口及原位置。排序选中标记改用项目现有图标，保留排序方向与当前排序信息。菜单项数量与回调保持完整。
2. **搜索区**：独立的纸面工具带，圆角 12dp，搜索图标、现有搜索提示与可访问名称清晰；有查询时提供清空入口。输入立即沿用 `onQueryChange`，`group:`、启用/停用、登录与发现状态筛选仍由既有查询解析负责。
3. **书源列表**：每条书源采用两段布局。上段是左侧选择框和可占满剩余宽度的名称区；名称最多两行，分组与域名以次级文字呈现。下段承载启用开关、编辑和更多操作，名称不再与全部控件争用同一条水平空间。默认行高由内容撑开，长名与大字状态自然增高。编辑和更多保持原语义名称与至少 48dp 触控区域。
4. **选择态**：整条条目使用轻量 `primaryContainer` 表面反馈，Checkbox 保留勾选状态；启用状态继续由 Switch 独立表达。整行长按仍专用于原有手动拖动，避免新增整行点击行为干扰开关、编辑或拖动。
5. **域名聚合**：保留 `stickyHeader` 与 `host:` 稳定键；标题采用浅层表面、主色小标题与细分隔。域名只显示数据来源；空域名沿用既有 `sourceHost` 结果。打开域名聚合后，拖动与置顶/置底继续按现有条件收起。
6. **检测行**：调试消息紧接对应书源工具区，起始线对齐名称；失败用 `error` 与原 Assertive live region，其他消息沿用 Polite。活动检测继续使用现有 `isChecking` 与消息判定显示小型进度。消息容器随真实内容出现，保留文本可达性与列表滚动位置。
7. **底部批量工具**：以纸面工具区和顶部分隔承接列表。第一层保留全选及已选/总数，第二层容纳反选、删除与批量更多，窄屏和大字状态下优先保证完整触控区域与计数可读性。未选择时相关动作继续禁用。系统导航栏 inset 沿用现有 Scaffold 链路。

## 分组管理布局与行为

保留现有 90% 窗口尺寸与嵌套 `AlertDialog` 流程。顶部使用同款书衣工具栏和新增入口；分组列表为连续纸面，每条显示分组名与编辑、删除控件，长名称允许换行，两个操作各保留 48dp 触控区域。列表首尾与主页面使用一致边距，行间采用细分隔。空状态使用现有“空”文案并保留顶部新增入口。

新增/编辑弹窗保留标题、分组名标签、单行输入、确认与取消。输入框圆角与主页面搜索框协调，错误与保存逻辑保持现有 ViewModel 行为。系统返回、外部点击关闭和 IME 避让由原生 Dialog 处理；避免新建平行的弹窗状态与临时业务状态。

已核对现有业务：`addGroup` 会把无分组书源加入指定组；`upGroup` 对已有组重命名或移除；`delGroup` 从书源中移除该组。视觉改动保持此数据语义与调用参数。

## 状态、动效与适配

| 状态 | 视觉与交互 |
| --- | --- |
| 正常/长名 | 标题与分组/域名分层；工具独立一行；文字按内容增高 |
| 查询无结果 | 保留查询和清空，显示现有空文案；空查询时继续提供新增书源 |
| 全选/部分选/无选择 | 沿用既有全选判断、选择数量及事件；批量工具禁用条件保持 |
| 书源停用 | Switch 状态与原 `stateDescription`；名称保持可读对比 |
| 有/无登录和发现 | 菜单分支保持；发现状态同时具备已有操作文字及状态语义 |
| 检测中/失败/结束 | 每条局部反馈与对应 live region，持续沿用真实检测数据 |
| 分组空/增/改/删 | 沿用 Room Flow 更新、稳定分组 key 与现有输入生命周期 |
| 夜间/自定义色/墨水屏 | 全部使用语义角色；墨水屏保留可识别分隔、控件与选择状态 |
| 窄屏/横屏/大字/IME | 允许行高与工具区增高，列表继续可滚动，关键操作保持可达 |

交互反馈优先复用现有 Material 控件和共享按压反馈；新增加的按压属性动画使用 `LocalLegadoMotion.current.pressSpec()`。状态与容器过渡使用现有 motion 时长，系统移除动画与墨水屏时立即落到最终态。保留 `rememberLazyListState`，筛选与排序沿用稳定键；避免整列表入场动画与无业务作用的交错。拖动判定与移动回调本轮保持原职责。
