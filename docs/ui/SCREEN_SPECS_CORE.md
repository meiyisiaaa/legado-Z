# 核心页面 SCREEN_SPEC（后续扩展）

状态：后续页面规格，依据当前页面源码与 [DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md) 编写。首轮实际 UI 实现集中在书架；发现、搜索、阅读器、订阅、我的与设置尚未按本规格重绘或验收。书架已执行检查的范围见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)，不推广到其他页面。

本规格只整理现有页面任务与视觉约束，不改变数据、书源/订阅/阅读引擎、导航契约或用户偏好。沿用 Material 3 语义颜色、现有主题与动效、4/8/12/16/24/32dp 间距、至少 48dp 触控目标和系统字体缩放。下述宽屏适配均为后续设计约束，不代表已实现。

## 发现与书籍搜索

- **主要任务：**发现页检索、筛选并展开书源分类；搜索页查找本地书或远端书源结果。
- **布局优先级：**保留工具栏搜索与已有分组入口；发现内容按书源列表组织，展开后显示该源的分类。未开始搜索时先呈现本地匹配与搜索历史；输入查询后展示结果列表。
- **焦点操作：**搜索/清除查询、选分组、展开书源、进入分类；搜索结果打开书籍，本地书与历史词可直接继续搜索，搜索过程可停止或继续加载。
- **状态与长文本：**发现页已有分组/书源加载反馈、空态与可重试错误；搜索建议有本地书和历史记录空态，结果扫描显示进度。当前搜索结果状态未暴露专用错误或“无结果”面板，不在本规格虚构。书名、书源名、简介和关键词需保持可辨识，不挤压操作；截断时辅助功能名称保留完整内容。
- **反馈与响应式：**加载和错误贴近对应列表，不覆盖搜索栏；后续若补齐搜索空态，应区分“无书源”和“无匹配”（当前搜索结果没有独立无匹配面板）。窄屏保持单列扫描，宽屏可增加行内可用宽度但维持结果层级；搜索输入时处理 IME 与滚动区域，保留键盘焦点和系统返回行为。

## 阅读器与目录

- **主要任务：**连续阅读当前章节、查看阅读进度、打开目录并跳转章节；通过现有阅读菜单访问翻章、进度和阅读样式等操作。
- **布局优先级：**正文/页面是阅读器主体；菜单、进度和章节信息为辅助控制。目录以章节顺序为主，明确当前章节，并保留章节标签、字数及缓存/VIP 标记等已有信息；当前章节摘要和目录首尾跳转位于目录操作区。
- **焦点操作：**翻页、打开/关闭阅读菜单、调进度、进入目录、选择章节、上一章/下一章。保留现有阅读手势、按键、返回和引擎调用路径。
- **状态与长文本：**目录已有加载指示、错误与重试、普通/搜索空态；定位当前章节并提供目录首尾跳转。阅读正文的空缺、加载和失败反馈继续遵循现有阅读器/引擎状态，不新增通用占位或重试业务。章节标题按目录单行省略，完整名称可访问；正文自然分页/排版，字体、字号、行距与颜色服从用户阅读设置。
- **反馈与响应式：**菜单开合、进度调整和章节选择使用现有反馈与 `LocalLegadoMotion`。宽屏仍控制正文行长并保留用户页边距/排版设置；目录延续现有打开与返回方式，不因屏幕变宽自动新增常驻分屏。

## 订阅

- **主要任务：**筛选订阅源分组、打开订阅、进入规则订阅；通过已有入口查看阅读记录、收藏、管理订阅源和排序。
- **布局优先级：**工具栏搜索/分组与操作菜单保持可达；订阅源入口按网格排列，规则订阅入口始终保留。订阅卡片以图标和名称为主。
- **焦点操作：**点按打开订阅；长按使用已有编辑、置顶、登录（源支持时）、停用和删除菜单；分组筛选继续走现有搜索查询。
- **状态与长文本：**当前订阅源为空时显示既有空提示，同时保留规则订阅入口。DAO 数据流没有页面级加载状态；异常目前记录日志且没有页面重试控件，因此不伪造骨架、错误按钮或把加载失败误报为空列表。订阅名最多两行显示并省略，辅助功能名称保留完整文本；图标加载失败沿用现有占位图。
- **反馈与响应式：**操作确认与提示延续现有对话框/消息。当前网格固定四列；后续适配应按可用宽度调整列数并维持足够触控面积，避免窄屏压缩卡片名称，宽屏不拉伸成难扫读的长行。新增可见数据流重试需另作产品定义。

## 我的与设置

- **主要任务：**进入书源与规则管理、主题/备份设置、书签、阅读记录和文件管理；在设置页查找并修改既有偏好。
- **布局优先级：**“我的”维持分组偏好列表：先呈现管理入口、主题模式和 Web 服务，再按现有分类组织备份恢复、主题、其他设置、书签、阅读记录、文件、关于与退出。配置子页保持标题、返回和分类内偏好顺序。
- **焦点操作：**打开入口、切换开关、选择偏好、返回上层；输入项弹出键盘时维持当前表单上下文。沿用现有 Preference 控件、确认对话框、成功提示和设置生效方式。
- **状态与长文本：**默认内容是可滚动的静态偏好列表，没有整页加载/空态；缓存清理等操作只展示源码已有的结果反馈，设置页错误不统一包装成全页错误。标题与摘要在字体放大或窄屏时可换行、扩展行高，不截断设置含义，也不遮挡开关和值。
- **反馈与响应式：**选中、禁用和修改结果使用原生/Material 语义并提供可见焦点。手机保持单列层级；较宽窗口可限制内容最大宽度并居中，仍保留同一滚动顺序和返回结构，不自行拆分或重排设置类别。
