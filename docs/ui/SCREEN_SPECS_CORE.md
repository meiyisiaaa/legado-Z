## 书架与阅读进度筛选

详细规格：[书架](SCREEN_SPEC_BOOKSHELF.md)、[阅读进度筛选](SCREEN_SPEC_READING_FILTER.md)。

- 普通列表采用共享 Serif `bookTitle` 18/26sp、两行书名和章节边注；紧凑列表保留一行书名，网格保持用户列数偏好并按宽度/字体缩放调整实际列数。列表、紧凑和列数是既有功能。
- 默认分组标签和文件夹宿主继续调用共享 `BookshelfContent`。点击、长按、分组、刷新、快速滚动和工具菜单沿原路径；真空、加载与错误保留实际状态。
- 阅读筛选提供全部 / 未开始 / 在读 / 已到末章。判据使用保存的章节索引、字符位置和真实目录数量：正向位置归为已开始，达到已知末章索引时归为末章。
- 筛选只在成功且非空的纯书籍组显示，文件夹根页和含文件夹页面保持原貌。页面状态按 `groupId` 保存，无结果仍可改选和显示全部；数据库、偏好与分组保持，宿主刷新/导出/管理继续覆盖原整组。
- 已到末章表达当前本地目录的位置；实际阅读完成和最新目录同步情况另行确认。零位置统一归为未开始。

## 发现与书籍搜索

详细规格：[发现与搜索](SCREEN_SPEC_EXPLORE_SEARCH.md)。实现位于 `ExploreContent.kt`、`SearchScreen.kt`，书名角色来自 `BookTypography.kt`。

- **发现：**书源使用 16dp 内容边缘、至少 48dp 展开目标、细分隔与展开区边线；源名最多两行，组名保留辅助层级。分类继续由原 renderer/slot 提供，原分组、查询及编辑/置顶/登录/搜索/刷新/删除菜单保留。
- **搜索：**66×88dp 封面与两行 `bookTitle`，作者、分类、最新章节、简介按层级组织；书架状态与来源数量有文字语义。保留历史、本地匹配、删除/清除、搜索停止/继续和分页回调。
- **状态：**发现保留分组、源与分类的真实加载和错误状态，具体原因与重试可达；真空与筛选无匹配分开。搜索按当前状态模型分别呈现扫描、手动暂停和无匹配，暂停保留继续入口。
- **输入与导航：**搜索焦点、IME Search、系统返回隐藏键盘、结果打开和已有封面过渡契约保持。本轮已运行常规、小屏、大字号、长内容及分类展开相关检查，分项结果见根验收报告。

## RSS 订阅

详细规格：[RSS](SCREEN_SPEC_RSS.md)。实现位于 `RssSubscriptionContent.kt`。

- 原规则订阅从源格子中独立为全宽入口，至少 56dp；源网格自适应宽度，最小单元 `104dp × max(1, fontScale)`，8dp 列距、16dp 行距、50dp 图标与两行源名。
- 保留 Fragment 工具栏、查询/分组、阅读记录、收藏、管理和排序；源打开、长按编辑/置顶/条件登录/禁用/删除及原图片加载通路保持。
- 真正无源时保留原提示及可达的规则入口，页面状态由现有 DAO 数据流提供。
- 条目稳定身份、按压与重排沿用现有动效和墨水屏/减少动画通路。本轮已运行规则入口、源菜单、长名与适配相关检查，实际主题和窗口覆盖见根验收报告。

## 我的与共享设置分组

## 目录与阅读器边界

详细规格：[目录](SCREEN_SPEC_TOC.md)。本轮实现仅重构 `ChapterListScreen.kt` 呈现层，阅读正文、阅读设置和引擎保持。

- 目录使用至少 48dp 章节目标、16dp 边缘、最多两行章名和卷分隔。当前章同时有 selected 语义、侧线、强调文字及勾选；缓存、未缓存、VIP、标签和启用的字数状态继续独立表达。
- 底部平面定位栏保留当前章摘要、首尾定位、点击/长按定位当前章。搜索按原结果索引定位，长按保留完整章名，替换规则继续在原异步路径刷新。
- 原目录/书签 Tab、搜索、菜单、倒序和开关由 `TocActivity` 拥有；数据、缓存和打开结果仍由原 Fragment 承接。
- 加载、普通空目录、搜索空结果、具体错误与重试保留；长原因可滚动。本轮已执行目录状态、章节操作、定位及窄屏/大字相关检查，48dp 定位按钮和 fixture 修复的复验结果见根验收报告。

## 书目备注

详细规格：[书目备注](SCREEN_SPEC_BOOK_NOTE.md)。实现包含 `Book.userNote`、DAO、Room 90→91 迁移及书籍详情/编辑内容与宿主。

- 备注在详情简介之后按需展示，并支持选择复制；编辑页在简介后提供独立多行输入和原保存入口。草稿与实体分开，Bundle 保存重建状态，保存动作负责持久化；空白输入存 null，非空保留原换行与空格。
- 备注独立于书源简介、自定义简介、脚本变量和章节书签。编辑采用定点列保存，活动文本/漫画/音频/视频模型只同步编辑字段；普通整书写入有保留已有备注的通路。
- 完整备份随 `Book` 保存备注，完整恢复沿用整书覆盖语义，包括旧备份中的缺省 null。普通书架分享继续使用原书目字段白名单，单本分享移除备注并保留其他原字段；旧 Web 整书保存保留本地备注，Web 进度同步沿用原进度字段。
- 本轮已执行迁移、备注持久化、真实换源/转本地和编辑相关检查。真实保存/取消、重建、输入法与截图修复的分项结果持续汇总到根验收报告。
