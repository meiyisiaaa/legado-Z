# 订阅媒体 · 选择、下载与相册保存

状态：已实现；本轮原画质、资源过滤与进度修复已通过 API36 常规及320dp小屏复验。本文记录当前实现契约，实测范围与待验项目统一记录于根目录 `VISUAL_REVIEW.md`；沿用现有 `APP_BRIEF.md`、`DESIGN_SYSTEM.md`。

## 主要任务与入口

读者在文章内选择媒体，或从订阅列表选中多篇文章，将图片和点播视频保存到系统相册。入口包括文章菜单「下载媒体」、订阅图片预览、订阅视频播放器，以及文章列表长按后的批量下载。订阅首页和选择面板均提供「下载任务」。现有打开文章、收藏、分页和五种列表布局继续使用。

候选默认全部未选；用户勾选后提交「下载所选（数量）」才创建下载任务。识别及打开播放器只发现候选。动态内容提供「识别动态媒体」「停止识别」，需要播放触发的文章提供「打开并识别」或「打开并播放」。

解析和动态识别期间允许勾选，提交按钮等待识别结束后启用，避免临时预览在原图替换前被下载。停止动态识别后可提交当前已识别的内容。

## 布局与视觉焦点

继承 A「矿绿书衣」的矿绿工具栏、纸面内容、细线索引与克制的排版。颜色来自 `MaterialTheme.colorScheme`，排版与形状使用共享主题，间距遵循 8/12/16/20/24dp。媒体缩略图承担内容识别，选择数量和提交按钮承担操作焦点；状态通过文字及进度共同表达。

- 列表长按进入多选，工具栏显示数量、全选、取消及下载操作；选择以稳定文章身份保存，刷新或分页保持合法选择。
- 选择面板按文章分组，显示媒体预览、类型、已有标签和真实可获得的大小，提供全选、取消全选及「下载所选」。大小、清晰度等信息缺失时省略，避免推算或补写虚构数值。
- 任务面板用连续索引行显示文章名、媒体类型、字节进度及状态。下载中支持暂停/取消，暂停后继续，失败后重试，完成后打开文件。
- 文字长短和未知大小自然收拢；操作至少48dp，窄屏允许操作换行，内容可滚动，主操作保持可达。

选择、播放识别和任务页共用专属 `RssMediaDialog` window：`windowIsFloating=false`、宽高 `MATCH_PARENT`，清除 decor 内边距与背景 dim，形成真正的全屏内容区域。window 使用独立主题、透明状态栏和导航栏、edge-to-edge 内容及对应安全区域；工具栏处理顶部 inset，底部内容处理导航栏 inset，系统栏图标亮暗跟随当前主题与墨水屏模式。工具栏返回依次退出内嵌播放、返回选择页或关闭面板，关闭后回到原文章上下文。

## 状态与反馈

| 状态 | 内容与反馈 |
| --- | --- |
| 正常 | 媒体按文章分组，独立勾选、全选及取消选择 |
| 加载/识别 | 明确的局部加载提示，保留已发现的候选，允许关闭面板取消识别 |
| 空 | 显示未发现媒体，并提供网页识别/打开播放入口 |
| 部分失败 | 已发现的候选仍可选；按文章展示可理解的失败信息及重试 |
| 等待下载 `queued` | 排队，提供暂停和取消 |
| 正在下载 `downloading` | 已知总量显示实际字节及进度；未知总量使用进行中指示；提供暂停和取消 |
| 已暂停 `paused` | 保留下载缓存，提供继续和取消 |
| 正在保存到相册 `exporting` | 独立保存状态与进行中指示，提供取消；HLS/DASH 从已下载缓存合并导出 MP4 |
| 下载失败 `failed` | 展示网络、登录、格式或媒体限制的具体原因，提供重试和打开原文 |
| 保存失败 `export_failed` | 展示空间、权限或编码相关处理提示，保留已下载缓存，提供重试和打开原文 |
| 已取消 `cancelled` | 停止任务并清理本轮半成品，提供重试 |
| 已保存到相册 `completed` | 显示已发布文件的实际完整大小，文件存在时可打开，重复提交复用结果；文件删除后可重新提交下载 |
| 长文本 | 标题可换行并在语义树保留完整名称；错误内容可滚动，不挤压操作 |

## 交互、平台与验收约束

识别由面板生命周期持有，停止时取消识别请求，关闭后销毁 WebView。已提交下载由前台服务持有，关闭页面后继续运行。选择控件提供可读名称与选中语义，状态使用适用的 live region，进度反馈遵循现有系统动态设置。

Android 10+ 使用 MediaStore 待发布条目，保存至 `Pictures/Legado` 或 `Movies/Legado`；Android 8–9沿用存储权限申请、临时文件和扫描入库。相册文件发布后，以任务仍处于 `exporting` 为条件绑定 URI 并标记完成：取消先成功更新状态时，清理本轮新建产物；完成绑定先成功时，后续取消沿用完成结果。绑定与清理完成后再释放缓存，避免显示“已取消”却遗留本轮相册文件。

下载阶段的字节数表示缓存中的网络媒体数据；完成状态的两个字节值统一为相册文件的真实大小，并与完成状态原子写入。轮询只更新等待或下载中的任务。打开任务面板时，按相册文件校准历史完成记录；HLS/DASH 重封装后以最终 MP4 的大小为准。

## 正文过滤与原始质量

图片按正文 DOM 及附件识别。排除明确的网站图标、头像、导航按钮、页眉页脚装饰和追踪像素；正文中的小图及漫画图保留。网络图片请求只用于网页自身加载，候选图片从 DOM 的内容语义中提取，防止缩略图与图标被再次加入。跨正文、当前 DOM 和已捕获候选合并时，同步移除已知预览版本。

来源明确提供 `data-original`、WordPress 原图属性或指向图片的链接时，优先使用该原图；`srcset` 与 `picture` 选择最大声明尺寸。保留原始签名参数，缺少原图线索时使用实际可获取的内容图地址。图片及直链视频按原始字节保存，不经缩放或重新压缩。

HLS/DASH 按清单选择主视频最高像素分辨率及默认音轨，下载选择独立于当前屏幕和播放解码器能力。MP4 兼容编码保留压缩样本并重封装；需要转码时保留原尺寸，关闭自动降低分辨率的编码回退。来源没有高清版本时沿用可获取版本；设备无法完成必要的原尺寸转码时进入保存失败并保留缓存。

Room 92 保存任务状态、进度、原始请求规则、实际 URL、请求头和输出 URI；91→92迁移保留既有文章、收藏，并为其新增默认空附件信息。暂停与进程恢复沿用持久缓存；暂停由用户继续，失败由用户重试。重试重新求值源登录头和 URL options，地址发生变化时引导回原文重新识别。

## 请求凭据与媒体限制

媒体请求以协议、主机、端口确定凭据所属目标。同域沿用源规则；跨域保留公共请求头，媒体 URL options 明确指定的目标凭据与该目标真实捕获头单独保留，Cookie 从目标域会话获取。源站 Authorization、Cookie 和自定义密钥随继承来源隔离。下载及媒体探测发生 302 等跨域重定向时，移除上一目标的私密头，再读取新目标 Cookie。地址无效时使用固定提示「媒体地址无效」，避免在该错误中输出签名参数。

按真实响应类型与媒体签名识别内容，登录页、错误页与伪装媒体进入失败状态。直播提示「实时直播流暂不支持保存，请选择已结束的点播媒体」；DRM 提示「DRM 加密保护媒体暂不支持保存」；SAMPLE-AES 提示「SAMPLE-AES 加密媒体暂不支持保存」。失败行保留「打开原文」，供用户回到原站播放或重新识别。
