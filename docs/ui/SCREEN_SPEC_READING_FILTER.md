# 书架 · 阅读进度筛选

## 目标与边界

在当前书架分组内，以只读视图查看「全部 / 未开始 / 在读 / 已到末章」。筛选由现有 `Book` 的阅读位置和本地目录总章数派生，不创建 `BookGroup` ID，不写数据库或偏好，不改手动分组、排序和布局。刷新、导出、管理继续使用宿主原有整组书籍；打开和长按仍回传原 `Book`。

## 数据语义

| 状态 | 规则 |
| --- | --- |
| 未开始 | `durChapterIndex <= 0 && durChapterPos <= 0`，没有正向阅读位置 |
| 在读 | 已有正向位置，且尚未达到下述末章条件 |
| 已到末章 | 已有正向位置、`totalChapterNum > 0`，且 `durChapterIndex >= totalChapterNum - 1` |

三种状态互斥且覆盖全部书籍。「已到末章」只表示达到当前本地目录的末章，不表示读完该章或作品完结，也不保证书源没有尚未同步的新章节。目录未知但有阅读位置的书归入在读。单章书须有正向字符位置才归入已到末章。

`durChapterTime` 默认即为当前时间，不能用来证明读过；不使用带模拟总章数的 `getUnreadChapterNum()` 判断末章。零位置不能区分尚未翻动首章、打开过首章和手动重置进度，统一归为未开始。

## 呈现与交互

- 筛选条置于分组标题之下、书目之上，使用现有 Material 3 语义色、`labelLarge`、8dp 间隔和 16dp 内容边界；条目触控目标至少 48dp。
- 使用横向可滚动的单选筛选条；窄屏与放大字体不挤压文案。当前项具有选中语义与勾选标记。列表保留稳定书籍身份和既有条目动画，减少动态模式沿用当前实现。
- 仅在加载成功、当前数据非空、`groupId != BookGroup.IdRoot` 且所有条目均为 `Book` 时显示。文件夹根页及含 `BookGroup` 的页面保持原貌，不会把文件夹过滤掉。
- 使用分组 `SaveableStateProvider(groupId)` 内的 `rememberSaveable` 保存当前筛选；切组各自恢复，重建可恢复，不持久化到业务数据。
- 真正无书、加载中和失败沿用原状态与重试，不把它们改成筛选无结果。
- 筛选无结果显示「没有符合条件的书籍」，保留筛选条与「显示全部」操作；可直接切换条件或清除条件。
- 普通、紧凑、网格、快速滚动继续生效。快速滚动仅针对当前可见结果定位；下拉刷新回调仍覆盖宿主整组。

## 验收

规则测试覆盖零位置、首章字符位置、单章书、未知目录、目录增长、越界索引和三状态互斥。独立 Compose 测试覆盖筛选、无结果清除、组间状态恢复、文件夹根页、网格/紧凑点击和长按、刷新边界及加载/错误/真空状态。
