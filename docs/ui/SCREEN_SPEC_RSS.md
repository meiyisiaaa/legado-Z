# RSS 订阅页规格

## 范围与依据

本轮调整主导航中的 RSS 订阅内容，沿用 `DESIGN_SYSTEM.md`、`UI_REFERENCES.md` 的阅读工具气质：内容直接落在主题表面，以文字和空间建立层级，不增加圆角大卡、阴影或装饰说明。MD3 仅作组件交互参考，布局独立设计。

保留 `RssFragment` 的工具栏、分组、搜索、源管理、阅读记录、收藏与导航；本轮仅改 `RssSubscriptionContent`。不更改数据库、登录、源排序、禁用和删除流程。

## 结构与排版

- “规则订阅”从普通源格子中独立为网格全宽入口，使用原有图像与文字、右向箭头和底部分隔。行高至少 56dp，文字自然增高；保持单次点击入口。
- 页面水平边界 16dp；规则入口与源网格分区，避免把规则管理误识别为内容源。
- 源使用自适应网格，最小单元宽度 `104dp × max(1, fontScale)`，列间距 8dp，行间距 16dp；常规手机通常三列，较宽窗口增加列数，小屏或大字减少列数。
- 源图标维持 50×50dp，使用既有 Glide/ImageLoader、原 placeholder/error 图、来源请求选项与裁切。图标到名称间隔 12dp。
- 源名采用 `bodyMedium`、`onSurface`、居中两行；保留两行空间以稳定同行基线，长名省略且完整文字保留在语义树。源目标至少 48dp，不压缩图标适配列数。
- 颜色、形状、图标和字体跟随现有主题，支持浅色、深色、墨水屏和用户主题，不另造色板。

## 行为、状态与动效

- 点击源保持打开行为；长按源显示原菜单，保留编辑、置顶、按 `loginUrl` 条件显示登录、禁用、删除及菜单关闭回调。
- 规则入口和源沿用项目按压缩放与 Ripple 约定，读取 `LocalLegadoMotion`；系统关闭动画或墨水屏不增加运动。
- 源项采用稳定 `sourceUrl` 身份与主题状态时长的列表增删/重排动画；菜单沿用 Material 3 的焦点、返回及关闭处理。
- 空源保留原 `rss_source_empty` 文案和可达的规则订阅入口，允许提示在窄屏换行并随页面滚动。
- DAO 当前没有提供独立加载/错误状态，本轮不添加假的 loading、错误和重试流程。

## 验证契约

在同一文件内保留原 Fragment 接口，并将呈现及菜单隔离为纯内容组件；图片由实际宿主提供，测试使用固定本地 drawable，不启动 Fragment、DAO 或网络。

`RssSubscriptionVisualTest` 覆盖规则入口、源打开、五种菜单回调、无登录源的条件菜单、空态、长名、窄屏和字体放大。截图沿用项目 UiAutomation 原生采集，输出到应用外部文件目录 `rss-visual/<visualPrefix>-<state>.png`，支持 `visualFontScale` 参数。

本轮已执行构建、源打开与菜单回调、空态和窄屏/大字体检查；原生截图与主题覆盖见 [VISUAL_REVIEW.md](../../VISUAL_REVIEW.md)。真实订阅网络、真机与 TalkBack 实际朗读列入后续验证。
