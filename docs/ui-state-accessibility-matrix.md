# Android Compose 页面状态与无障碍矩阵

本矩阵归纳 Android 逻辑页面/功能簇的适用状态与无障碍要求，并标记静态核对、历史 runtime 和本轮实际运行证据；它不是全覆盖或最终通过证明。页面与宿主按 docs/ui-redesign-acceptance.md 的分组、本轮相关 Compose 源码差异和既有 androidTest 证据归并。当前唯一 class.test 合并为 70/70 PASS、30 classes（R71 68 项 + R74 SearchView 2 项），仅支持列明断言；R71 TalkBack service bridge 1/1 只验证 framework focus/action/selection。未被对应测试覆盖的状态仍待运行或人工操作验收。逻辑簇不是源码文件计数，目录扫描候选也不是页面数量或覆盖率。

目录扫描得到 67 个同时含 @Composable 且文件名匹配 Content、Screen 或 Activity 的 Kotlin 源文件候选；这是工具检索结果，不等同于页面数量或覆盖率。下表按验收材料中的逻辑页面/功能簇归并宿主。

## 状态与证据标记

| 标记 | 含义 |
|---|---|
| D | 默认、稳定显示状态。所有页面都需要检查。 |
| L | 数据读取、刷新、提交或生成过程中的加载状态。只在该页面实际执行异步工作时适用。 |
| Ø | 列表、搜索或选择器没有结果/数据时的空状态。表单或固定设置面板没有列表时通常 N/A。 |
| E | 可恢复的本地读取、解析、持久化或校验错误。适用于确有 I/O 或可失败校验的本地页面；若页面只有纯偏好、没有 I/O，也没有可恢复失败路径，则 N/A。 |
| O | 网络离线或远程服务失败。只适用于实际发起联网/Provider 请求的页面或子流程；本地列表/偏好页不因同属一个功能簇而自动适用。 |
| d | 操作不可用时的禁用状态，例如没有选中项、输入无效或到达范围边界。 |
| S | 操作成功后的结果状态，例如保存后回读、收藏已选中、任务完成或回到原列表。若产品只通过持久化回读反馈成功，应检查回读，不假设有成功提示。 |
| P | Android 系统权限的允许、拒绝、撤销或重新授权状态。只有相机、SAF/文件或明确调用系统能力的入口适用；一般设置表单 N/A。 |
| X | 极端输入与布局：长名称/长文本、空白与超长输入、密集列表、无选中项、窄屏和系统字体放大、滑块边界。按该簇实际数据选择。 |
| N/A | 不适用；每项都说明原因。若页面存在状态但当前没有实现或证据，标为“待核对”，不能写成 N/A。 |

证据分为三层：静态核对是当前源码中的状态分支/语义；历史 runtime 只对报告所列构建、设备和路径有效；本轮 runtime 只适用于有同一版本结果的明确测试与路径。R74 自动化和 debug 运行已验证 SearchView 定向测试、320dp RSS 的输入/清除、IME/filter 恢复及 Discovery 日/夜与 fontScale=2；汇总为 70/70 PASS、30 classes。R74 release R8 已构建、签名、安装，`build/ui-redesign-validation/native/api36-r74-runtime-summary.json` 的 21/21 指定 XML/路径/版本/对比断言通过，非额外 instrumentation。R72/R73 历史包发现详见 docs/ui-redesign-acceptance.md；其他未列状态仍须测试或人工操作。
