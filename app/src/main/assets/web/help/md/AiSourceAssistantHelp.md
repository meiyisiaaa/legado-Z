# AI 书源助手

用大模型帮你**生成**或**诊断**书源规则。

## 生成模式
- **意图**：用一句话描述你想要的书源，例如「帮我做这个站的搜索和目录规则」。
- **页面地址（可选）**：填了才会联网抓取该页 HTML；留空则只用下方粘贴的 HTML。
- **网页 HTML（推荐）**：直接粘贴网页源码片段。不耗接口流量、更快，也避免把地址透露给第三方。

## 诊断模式
- **书源 JSON**：粘贴现有书源。
- **故障症状**：例如「搜索有结果但目录为空」。
- **样例 HTML**：出问题页面的源码片段（可选，有助于定位规则）。

> 诊断模式**不会**自动联网抓取任何页面，所有分析都基于你粘贴的内容。

## 结果
- **诊断建议**：模型给出的排查思路。
- **规则预览**：把书源关键字段拆成可读的「键 = 值」列表。
- **原始回复**：模型返回的全文，可点「编辑 JSON」手工调整。
- **一键导入**：只有当抠出的 JSON 通过校验、且无致命错误时才可导入。

## 隐私
- API Key 仅保存在本机私有存储，不会随备份导出。
- HTML 片段只在你点击「生成」时上传给你配置的接口。
- 调试/诊断不会把任何 URL 交给模型去抓取。

## 配置
点右上角「AI 配置」填写接口地址、API Key、模型名等；或到「设置 - 其它设置 - AI 配置」进入。
